# 📊 ASEAN DSE Master Analytics Hub 🚀

An end-to-end data pipeline and interactive dashboard designed to reverse-engineer winning strategies for the **ASEAN Data Science Explorers (ASEAN DSE)** competition.

This project uses Google's latest Gemini AI models to automatically extract structured data from hundreds of complex PDF storyboards, and then visualizes that data in a powerful Streamlit application to find the ultimate "Winners' Playbook."

## ✨ Features

- **🤖 AI PDF Extractor:** A robust Python script that bulk-processes 15-to-20-page PDF presentations. It uses `gemini-3.5-flash` (with a built-in auto-fallback engine) to extract specific metrics like target SDGs, beneficiaries, and tech stacks into a clean CSV format.
    
- **📈 Interactive Dashboard:** A dynamic Streamlit web application that visualizes 8 years of competition data.
    
- **🥇 The Winners' Playbook:** Symmetrical tab analysis that compares the "Overall" applicant pool against "Podium Finishers" to spot competitive deltas.
    
- **🗣️ NLP Buzzword Analyzer:** Automatically analyzes the brief descriptions of winning pitches to show you exactly what vocabulary resonates with the judges.
    
- **🧹 Auto-Cleaning Pipeline:** Built-in Pandas logic that dynamically fixes AI hallucinations and cross-pollination errors before drawing the charts.

## ⚙️ Installation & Setup

### 1. Clone the Repository

Download this code to your local machine.

### 2. Install Dependencies

You will need Python installed. Open your terminal and install the required libraries:

```
# For the Dashboard:
pip install streamlit pandas plotly

# For the AI Extractor Script:
pip install google-genai pydantic
```

### 3. Set Up Your API Key (For Extraction Only)

If you intend to run the `main.py` script to process _new_ PDFs, you must have a Google Gemini API key.

1. Get a free API key from [Google AI Studio](https://aistudio.google.com/app/apikey "null").
    
2. Open `Storyboard Extractor Script/main.py` and replace the `API_KEY` string with your key.
    

## 🚀 Usage

### Part 1: Running the Dashboard (Data Visualization)

If you just want to analyze the existing data, you only need to run the Streamlit app.

Navigate to the dashboard folder in your terminal and run:

```
streamlit run app.py
```

_A local web server will spin up and automatically open the dashboard in your default web browser._

### Part 2: Running the Extractor (Processing New PDFs)

If you have downloaded new PDF storyboards from a recent competition year:

1. Place the PDFs in a folder named after the competition year (e.g., `../2026/`).
    
2. Ensure the file names follow the format: `[Rank Number] [Country] - [Team Name].pdf` (e.g., `1 MALAYSIA - Team Alpha.pdf`).
    
3. Run the script:
    

```
python main.py
```

_The script will safely upload the PDFs, extract the JSON data, append it to your CSV and Markdown archives, and clean up the cloud storage._
